# funtv.in

Your ultimate hub for free resources on the internet.

Curated links to the best free streaming, software, books, games, AI tools and more.

## Stack

- React 18 + Vite
- Tailwind CSS
- React Router
- Lucide Icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Auto-deploys to Vercel on push to `main`.
